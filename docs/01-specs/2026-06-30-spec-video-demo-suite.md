## [S1] 目标

为 PMAer v0.2.0 制作一套产品演示视频，用于对外宣传和功能教学。

- **产品总览**：1个，60秒，覆盖产品定位和核心亮点
- **功能短片**：7个，各30秒，每个覆盖一个核心功能
- **总计**：8个视频，总时长约4分钟

## [S3] 技术规格

### 分辨率与格式
- **分辨率**：1280×720 (720p)
- **帧率**：30fps
- **编码**：H.264 (libx264)
- **输出**：MP4, movflags +faststart

### 制作方式
- **非录屏**：用 HTML/CSS/JS 动画模拟产品界面
- **设计语言**：参照现有 mockup（Ant Design 风格、蓝色主题 #1677ff）
- **数据**：使用模拟数据（项目名、金额、文件名等）

### 转换流程
```
HTML动画 → Playwright headless录制(WebM) → ffmpeg编码(H.264 MP4)
```

遵循 html-to-video-pipeline 技能：
1. viewport = recordVideo.size (1280×720)
2. addInitScript 冻结动画
3. goto + domcontentloaded
4. 字体等待 + unfreeze
5. 录制 → trim lead-in → 编码

## [S4] 动画设计原则

### 界面模拟
- 用 HTML 还原产品关键界面（不必100%还原，抓住核心视觉特征）
- 界面元素用 CSS 动画逐步呈现（fade-in, slide-up）

### 文字标注
- 每个场景开头有标题文字（如"AI智能分类"）
- 关键操作步骤添加气泡标注（白色背景 + 圆角 + 阴影）

### 转场
- 场景间用淡入淡出（opacity 0→1, 300ms）
- 界面元素用错开动画（stagger 100-200ms）

### 节奏
- 每个场景 5-8 秒
- 总览视频节奏更快（3-5秒/场景）
- 功能视频节奏适中（5-8秒/场景）

### 配色
- 主色：#1677ff（蓝色）
- 成功：#52c41a（绿色）
- 警告：#faad14（黄色）
- 错误：#ff4d4f（红色）
- 背景：#f5f5f5
- 文字：#1a1a1a / #666666

## [S7] 验收标准

1. 每个视频时长符合设计（±5s）
2. 720p分辨率，画面清晰无模糊
3. 动画流畅，无卡顿或跳帧
4. 文字标注清晰可读
5. 转场自然，无突兀切换
6. 无FOUT（字体闪烁）
7. 开头无死帧（空白画面）
8. ffprobe验证时长一致
