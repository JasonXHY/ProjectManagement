# PMAer 文档

> 版本：v0.2.0 | 更新时间：2026-06-30

---

## 文档结构

```
docs/
├── 00-INDEX.md           # 文档索引（Agent 入口）
├── 01-specs/             # 需求规格（25 files）
├── 02-plans/             # 实施方案（20 files）
├── 03-reports/           # 复盘报告（10 files）
├── 04-guides/            # 开发指南（10 files）
├── 05-issues/            # 问题记录（2 files）
├── 06-archive/           # 历史归档（18 files）
├── 99-mockups/           # UI 原型（3 files）
└── screenshots/          # 截图（24 files）
```

## 目录职责

| 目录 | 存放什么 | 不存放什么 |
|------|---------|-----------|
| `01-specs/` | 功能需求、接口规格、数据模型 | 实现方案、测试用例 |
| `02-plans/` | 实施方案、架构设计、重构计划 | 已完成的方案（完成后移 03） |
| `03-reports/` | 复盘报告、审查报告、测试报告 | 进行中的分析 |
| `04-guides/` | 开发规范、工作流程、用户手册 | 项目特定的临时说明 |
| `05-issues/` | Bug 记录、问题排查、根因分析 | 已解决的问题（解决后移 06） |
| `06-archive/` | 历史文档、过时方案、旧版记录 | 当前活跃文档 |
| `99-mockups/` | UI 原型、设计稿 | 代码实现 |

## 文件命名规范

```
[日期]-[类型]-[简述].md
```

类型代码：`spec` / `plan` / `report` / `guide` / `issue`

## Agent 使用指南

1. **启动时**：读 `00-INDEX.md` 了解文档结构
2. **排查问题时**：去 `05-issues/` 找相关问题记录
3. **执行任务前**：去 `02-plans/` 找实施方案
4. **总结进度时**：去 `03-reports/` 找复盘报告
5. **新会话开始**：读 `04-guides/` 了解开发规范
